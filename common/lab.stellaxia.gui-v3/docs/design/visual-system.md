# 화면 체계

'정돈된 콘솔' 방향의 구현 명세다. 글자 장과 터미널 정체성은 그대로 두고, 위치와 상태가 늘 보이게 하고 색을 토큰으로 묶었다. 사용자 조사 자료는 없다 — 근거는 설계 문서([[menu-hierarchy]] R-4 · R-5, [[design-ops-gaps]])와 2026-11-09 mock 화면 점검이다.

## 1. 토큰

정의는 `web/src/ui/base.css`. 창 보드 · 전역 틀 DOM 은 `var(--t-*, 다크값)` 으로 읽는다 — 캔버스(시안)에는 토큰이 없어 뒤의 다크값으로 그려진다. 새 창의 색도 이 꼴로 쓴다.

| 토큰 | 다크 | 라이트 | 쓰임 |
| --- | --- | --- | --- |
| `--t-bg` | `#040614` | `#f3f5ee` | 창 바탕 |
| `--t-text` | `#d6f4de` | `#14281e` | 값 |
| `--t-mut` | `#9cc4a8` | `#39574a` | 보조 글 |
| `--t-key` | `#709c80` | `#4d6a5b` | 항목 이름 |
| `--t-hint` | `#86ab95` | `#4d6a5b` | 가장 약한 글 |
| `--t-acc` · `--t-hi` | `#78e89c` · `#d0ff96` | `#0f6a3b` · `#0b5a30` | 강조 · 선택 · 키보드 초점 |
| `--t-ok` · `--t-warn` · `--t-err2` | `#60e28c` · `#ffd27a` · `#ff9c8c` | `#0f6a3b` · `#7f5300` · `#b0261b` | 상태 |
| `--t-off` | `#a6adb8` | `#59616e` | 모름 · 대기 |
| `--t-line-rgb` | `70,160,108` | `60,112,86` | 선(알파로 세기 조절) |

글자 대비는 모두 4.5:1 이상이다. 기존 `#548064`(4.46:1) · `#4f6e5a` 는 `--t-hint` · `--t-key` 로 올렸다.

## 2. 다크 · 라이트

- 기본은 다크. 제어기 › 설정 › GUI 의 '라이트 테마' 스위치로 바꾸고 이 브라우저에 남는다(`terra.theme`, 노드 데이터 아님).
- 라이트에서 밝아지는 것은 **창**이다. 글자 장 · 지도는 어두운 화면 그대로 둔다 — CSS filter 로 뒤집으면 구멍 칸과 궤도가 무너져서(측정함) 뺐다. 지도 자체의 라이트는 그리는 코드의 색을 나눠야 하는 별도 작업이다.
- 제어기(노드 데스크톱)는 자기 테마(`nx-dark`/`nx-light`)를 쓴다. 전역 테마와 잇지 않았다.

## 3. 지도 상태 (장면 가운데 카드 · 제어기 › 설정 › GUI)

상단 상태 줄(`StatusBar`, 0.5.6~0.6.6)은 0.6.7에서 없앴다(11/15 사용자 결정). 줄에 있던 것은 이렇게 옮겼다.

| 줄에 있던 것 | 지금 |
| --- | --- |
| 위치 경로 | 전역 틀의 지금 위치 · 지도 이동 |
| 알림 · 창 | 전역 틀의 알림 항목(안 읽음 수) · 레벨바의 최소화 창 |
| 계정 · 로그아웃 | 전역 틀의 계정 이름 · 로고 → 로그아웃 줄 |
| 테마 전환 | 제어기 › 설정 › GUI '라이트 테마' |
| 연결 상태 · 다시 시도 | 제어기 › 설정 › GUI '지도 상태' |
| 못 받음 · 없음 카드 | 장면 가운데 카드(`MapCard` 보드) — 줄 없이 남김(사용자 결정 "가운데 카드 남겨") |

지도 상태 글과 카드 판정은 `web/src/api/map-state.js`(`window.TerraMapState`)가 만들고, 설정 › GUI 와 가운데 카드가 같은 것을 읽는다. "못 봤음"과 "없음"을 섞지 않는다.

| 상태 | 글 | 색 | 자세히 · 가운데 카드 |
| --- | --- | --- | --- |
| 시안(`?demo`) | 시안 데이터 | off | — |
| 받기 전 | 지도 받는 중… | off | — |
| ok | 노드 N · 연결 안 됨 k · 방금 / Nm 전 | ok / warn | — |
| empty | 노드 없음 | off | 카드 "이 Tree 에 노드 없음" |
| error, 받은 적 있음 | 노드 목록 못 봤음 · Nm 전 사본 + 다시 시도 | err | 마지막으로 받은 지도를 보이는 중(카드 없음 — 지도는 마지막 사본) |
| error, 받은 적 없음 | 노드 목록 못 봤음 + 다시 시도 | err | 카드 "노드 목록을 받지 못함" + 다시 시도 |

카드는 지도를 한 번도 못 받았거나(error · 지도 비어 있음) 받았는데 정말 없을 때만 뜬다. 사본이 있는 채 실패하면 카드 없이 지도는 마지막 사본 그대로이고, 그 사실은 설정 › GUI 에만 말한다. 값이 바뀔 때만 다시 그린다(폴링에 깜박이지 않게).

## 4. 지도 이름표

실제 지도의 노드만. 온라인은 그대로, 문제가 있으면 이름 뒤에 상태 글자를 붙이고 색을 바꾼다 — 저하(warn) · 꺼짐 · 응답 없음(err) · 대기(off). 값은 `nodeStats`(하트비트 2분) 그대로, 5초 캐시.

## 5. 창 상태 띠 (`StateBand`)

창 윗부분. 같은 모양, 태그로 구분한다.

| kind | 태그 | 언제 | 쓰는 창 |
| --- | --- | --- | --- |
| `load` | 받는 중 | 아직 답이 없음 | 상태 · 네트워크 · 알림 · 자원 상태 |
| `none` | 없음 | 받았고 정말 없음 | 상태 · 네트워크 · 자원 상태 |
| `fail` | 못 봤음 | 읽기 실패 | 상태 · 네트워크(읽지 못한 칸) · 자원 상태 |
| `cut` | 끊김 | 마지막 사본 · 읽기 전용 | 모듈 상태 |

제어기 · 설정 · SVI · 자원 창의 빈 상태는 각자의 글을 그대로 쓴다(이번 범위 밖).

## 6. 접근성

- `:focus-visible` 2px 윤곽.
- 창 안 단추 최소 24×24(WCAG 2.5.8).
- 상태는 색 말고 글자로도 말한다(이름표 · 태그 · 점 옆 글).
- 지도 캔버스 자체는 키보드로 조작할 수 없다 — 노드 접근은 우클릭 · 전역 틀이 그대로다.
