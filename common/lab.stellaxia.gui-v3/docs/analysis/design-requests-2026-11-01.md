# gui-v3 디자인 요청서 (2026-11-01)

현재 main GUI(gui-v3 0.3.0 + #146)를 Terra 기능과 대조해 찾은 공백 중, **화면 설계가 먼저 필요한 것**만 모았다. 이 문서의 대상은 디자인 세션이다. 기능 배선(데이터 연결 · 가짜 값 제거 · 거절 처리)은 별도 구현 세션이 맡고, 아래 "상태 정의"에 적힌 빈 상태 · 잠금 상태가 그 세션과 디자인의 접점이다.

근거와 기존 정본: `design-ops-gaps.md`(H1~H8, M1~M8, L1~L4), `replacement-readiness.md` §3. 줄 번호는 origin/main 기준이며 고치기 전에 다시 확인할 것.

## 0. 먼저 알아야 할 것

- 사용자가 본 "node id · 상태가 안 보인다"는 이 PC 설치본이 0.3.0이라 #146(상태 창 실데이터 + node id 복사)이 없기 때문이다. 설계 결함이 아니라 배포 지연이다. 그래도 아래 D1은 전역 틀 쪽 공백이다.
- 실데이터가 없을 때 **값을 지어내 보이지 않는다**가 전제다. 모든 요청의 "빈 상태"는 `—` 또는 "보고 없음"이다.

## 1. 요청 목록

### D1. 전역 틀 "대상" 표 열 (근거 `design/Field.dc.html:175-193`)
- 지금 5행(이름 · 역할 · 상태 · 자원 · 가동)에 **node id(줄임 + 복사)**, **릴레이 연결 여부**, **CPU/MEM 값**, **마지막 갱신 시각 + 새로고침**을 어떻게 얹을지.
- 상태 4값에 **응답 없음(하트비트 N분 초과, 마지막 n분 전)** 표현 추가. 지금은 Master가 준 `status`를 그대로 보인다.
- 복사 패턴은 `NodeStatus.dc.html:56,142`의 `copyId`를 기준으로 등록 탭(`NodeDesktopEmbed.dc.html:332`)에도 같은 모양으로.

### D2. 전역 틀 "유틸" · "설정" 메뉴 12개 (`Field.dc.html:469-470`, 클릭 시 `'tool'` → `return;`)
- 동작하지 않는 항목(터미널 · 파일 전송 · 네트워크 진단 · 로그 보기 · 모듈 배포 · 계정 · 세션 · 사용자 · 권한 · 알림 등)을 **숨길지, "준비 중"으로 잠글지** 표현을 정하라. 동작하는 항목과 한눈에 구분되어야 한다.
- 알림 항목은 D3과 연결.

### D3. 알림 목록 화면 (신규)
- `alarms.js`가 알림을 만들지만 상태 줄에 5초만 보이고 사라진다(`main.js` `say`). 최근 50건 목록(시각 · 종류 · 메시지), 비었을 때, 읽음 처리.
- node-gui에는 알림 화면이 있었다(`node-gui/web/src/screens/node.js:2602`).

### D4. 리프 13개 이상 (`topology.js` `MAX_LEAVES=12`, `more()` 사용처 없음)
- 지도에서 12개를 넘으면 지금은 표시 없이 사라진다. "+n개" 표시와 펼침 · 목록 전환.

### D5. Tree 자신(Master)과 단독 리프의 부모 표시 (`topology.js:22-25,60`)
- Master는 노드 목록에 없어 id도 상태도 없다. "Master(노드 목록에 없음)"를 어떻게 보일지. 가능하면 master_url과 health 한 줄.

### D6. "잠금과 이유" 공통 패턴
앱 토큰으로 위임되지 않아 못 하는 일이 많다(이름 · 부모 변경, 삭제, 등록 코드 발급 · 폐기, 사용자 · 권한, 코어 업데이트, Fleet, 모듈 게시 · 승격). 지금은 버튼이 없거나 가짜가 있다.
- 잠긴 버튼의 모양, **필요한 권한 이름**(`node.config` 등) 툴팁, "대신 할 곳"(CLI 명령 또는 Tree 콘솔) 문구의 공통 틀 하나.
- 설정 → Terra 쪽에 "여기서 못 하는 일과 하는 곳" 안내 한 면.
- 원격 노드는 직계 자식만 닿는다는 제한도 같은 틀로("이 노드에서만").
- 참고: node-gui도 잠금 + 이유를 보였다(`node-gui/web/src/data/node-live.js:81-87`).

### D7. 노드 목록을 못 받았을 때의 지도
- 실모드에서 `nodes.get`이 실패하거나 비었을 때 시안 지도로 떨어지던 것을 **"노드 없음 / 못 받음"** 빈 지도로. 재시도 버튼 포함.

### D8. 세션 · 연결 안내
- 세션 만료(토큰 갱신 실패)를 상태 줄이 아니라 **상단 배너**로.
- Gateway에 닿지 못할 때 "진단" 버튼(헬스 · 준비 · 라이브 결과를 보이는 작은 면).

### D9. 가짜였던 창의 실모드 모습
데이터 세션이 가짜 값을 걷어내면 아래 창에 빈 자리가 생긴다. 빈 상태 표현을 정하라.
- 노드 설정 창 NodeConf: 가짜 node id · 사용자 · 등록 코드 자리(`NodeConf.dc.html:185,193,262,282,303`).
- 모듈 상태 창 ModStatus: CPU/MEM 값이 없을 때(`—`), 로그는 `modules.by-module-id.logs.get`로.
- 정보 탭(`NodeDesktopEmbed.dc.html:1540` `X.info`): 값이 없을 때.
- 터미널: 실모드에서 고정 출력 대신 무엇을 보일지(숨김 또는 읽기 전용 명령만).
- 웹 브라우저 창 WebBrowser: 외부 사이트는 iframe 삽입이 거부되는 경우가 많다(예: google.com이 "콘텐츠 거부"로 뜸). 거부를 감지했을 때의 안내와 "시스템 브라우저로 열기".

### D10. 파일 관리자 확장
- 파일 내용 **미리보기 · 내려받기 · 올리기**(현재 목록 · 들어가기 · mkdir · 삭제 · 바탕 열기까지). `entries.read`, `transfers.*`(후자는 위임 밖이라 D6 잠금 틀 사용).

### D11. 목록 필터
- 모듈 · 작업 · 노드 목록의 이름 검색(현재는 노드 설정 탭 한 곳뿐, `NodeDesktopEmbed.dc.html:297`).

### D12. 로그인 화면의 못 옮긴 부분
- PR #145가 못 옮긴 것: 글자 장 · 여는 연출 · 칸 글자 입력 · TREE/LEAF · auto 유지 · New Tree · 글꼴 · 색 · Esc (`main-scene.md` §1-1). 비밀번호 입력을 호스트 소유로 유지하는 보안 규칙 안에서 어디까지 가능한지가 쟁점이라 코어 설계(자격 필드 엘리먼트) 결정이 필요하다.

## 2. 구현 세션과의 접점

| 요청 | 구현 세션이 맡는 것 |
|---|---|
| D1 | `RN`/`NS`의 node_id · relay · 값을 표에 전달, 갱신 주기 |
| D2 | 항목별 동작 여부 플래그 |
| D4 | `more()` 데이터 |
| D5 | master 정보 로드 |
| D6 | `canRemote` · `permissionsOf` 값을 화면에 노출 |
| D7 | 실모드 실패 시 시안 대신 빈 상태 신호 |
| D9 | 가짜 값 제거, 모르는 `gui-v3.*` 쓰기 거절 |

## 3. 디자인이 정할 필요 없는 것 (구현 세션 몫)
모듈 끄기 · 켜기가 가짜 성공을 내는 문제(H2), 위성 가짜 자원(H4), 정보 탭 고정값(M3 · M4), 지도 갱신 주기(M2)는 동작 수정이다. 표현이 필요한 부분만 위 D번호에 있다.
